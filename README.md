# Aerodynamic-Optimization-Design-Space-Analysis-of-a-NACA-2412-Cessna-Wing
Developed and automated a 50-design XFLR5 optimization framework using VLM/LLT, identifying AR7.50_TR0.47_TW2.00 as the optimum with (L/D=31.59) (16.2% improvement) while satisfying stall and stability constraints, validated within 1.5% using the 3D Panel Method.
